# Sero SaaS Website System

## Core Principle

A SaaS website is not a brochure.  
It is a decision system.

Every page should move the visitor from:
unclear → interested → convinced → action.

---

## Global Rules

- One primary goal per page
- One primary CTA per page
- Every section answers one question
- Write for scanning, not reading
- Focus on outcomes, not features

---

## Page Types & Blueprints

### 1. Homepage

**Goal:** create clarity, relevance, and momentum

**Structure:**
1. Hero (outcome + differentiator)
2. Problem recognition
3. Solution framing
4. How it works
5. Capabilities / modules
6. Proof (logos, results)
7. CTA

---

### 2. Solution Page

**Goal:** show how a specific problem is solved

**Structure:**
1. Problem deep dive
2. Impact of not solving it
3. Sero solution
4. How it works (specific)
5. Product mapping
6. Proof
7. CTA

---

### 3. Product Page

**Goal:** explain what the product does and why it matters

**Structure:**
1. What it does (one-liner)
2. Key use cases
3. How it works
4. Impact / results
5. Integration / fit
6. CTA

---

### 4. Case Page

**Goal:** prove results and reduce doubt

**Structure:**
1. Situation
2. Problem
3. Solution
4. Execution
5. Results (numbers)
6. Quote
7. CTA

---

## Section Templates

### Hero Section

**Goal:** immediate clarity + relevance

- Headline → outcome
- Sub → how / differentiator
- CTA → low friction

---

### Problem Section

**Goal:** recognition

- Describe current situation
- Highlight inefficiencies
- Make it relatable

---

### Solution Section

**Goal:** shift perspective

- Introduce new way of working
- Position Sero as the layer
- Keep it simple

---

### How It Works

**Goal:** reduce complexity

- 3–4 steps max
- Clear and visual
- Logical flow

---

### Proof Section

**Goal:** build trust

- Results (numbers)
- Logos
- Short quotes

---

### CTA Section

**Goal:** trigger action

- One clear action
- Reduce friction
- Reinforce value

---

## Copy Depth Rules

- Max 2–3 sentences per paragraph
- Max 5 bullets per list
- One idea per section
- Use subheadings frequently
- Avoid long blocks of text

---

## SaaS Conversion Patterns

### 1. Replace vs Improve

Don’t position as improvement.  
Position as replacement of old way.

---

### 2. Before → After

Show transformation clearly.

Before: fragmented tools  
After: one intelligent system

---

### 3. Layer, not Tool

Position Sero as a layer on top of the stack.

---

### 4. Time-to-Value

Emphasize speed of implementation and results.

---

### 5. Works With Your Stack

Reduce risk perception.

---

## CTA System

### Primary CTA

- Plan your demo
- Always visible
- High intent

### Secondary CTA

- See how it works
- Explore product

---

## Common Mistakes

- Too much focus on features
- No clear structure
- Multiple competing CTAs
- Vague messaging
- No proof

---

## Formula

Clarity + Relevance + Proof + Simplicity = Conversion

---

## Claude Prompt

Write SaaS website copy using this system:

- Follow the page structure strictly
- Focus on business outcomes
- Keep sentences short and scannable
- Use clear section hierarchy
- Add proof and specificity
- Guide toward one primary CTA

Position Sero as:
- an AI layer
- a decision engine
- a system for scalable growth

Avoid:
- corporate language
- vague claims
- long paragraphs

Always optimize for clarity, speed, and conversion.
