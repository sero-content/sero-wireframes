Sero CDP

Je klantdata weet al meer dan je denkt. Sero CDP legt het eindelijk naast elkaar.

Elk klikpad, elke aankoop en elk e-mailadres wordt automatisch één profiel, niet drie losse. Sero CDP ontdekt daarna zelf welke segmenten ertoe doen en zet die om in actie: op de site, in e-mail of in je advertentiekanalen.

Elke aanbeveling wordt standaard getest tegen een controlegroep. Personaliseren is hier geen gokwerk.

S4 · Hoe het werkt
In vier stappen

Van eerste klik tot geactiveerde aanbeveling

1
Verzamel: plaats de Sero Pixel of koppel je bestaande BigQuery-warehouse. Elk klikpad, elke aankoop, elke korting wordt data.
2
Eén profiel: zodra een bezoeker koopt, een e-mailadres achterlaat of een korting gebruikt, wordt de sessie gekoppeld aan een profiel. Ook bij meerdere e-mailadressen.
3
AI ontdekt: AI herkent je type winkel, benchmarkt je tegen vergelijkbare merken en signaleert wat opvalt, inclusief wat je eraan kan doen.
4
Activeer, altijd getest: zet de aanbeveling live via een widget, journey of Klaviyo, Copernica, DeployTeq, altijd in A/B, nooit als takeover.
S5 · Use cases
Wanneer gebruik je Sero CDP?

Eén profiel, overal bruikbaar

Anonieme bezoeker naar bekend profiel

Een bezoeker koopt of laat een e-mailadres achter en wordt automatisch een "identified customer". Alle eerdere anonieme sessiedata wordt direct aan dat ene profiel gekoppeld, ook als iemand meerdere e-mailadressen gebruikt.

Abandoned cart en lifecycle-flows

Bouw journeys op basis van gedrag: cart abandonment, wachttijd, e-mail via Klaviyo, en een onsite banner als er na 24 uur nog niet gekocht is. Volledig visueel op te zetten, geen developer nodig.

Productaanbevelingen die kloppen

De recommendation engine combineert laatst bekeken producten met populariteit en categorie, en zet dat om in een aanbevolen-productfeed. Rechtstreeks bruikbaar in bestaande widgets op je site.

Retentie op bestaande klanten

Het ingebouwde RFM-model segmenteert bestaande klanten op recency, frequency en monetary value, met uitleg voor wie het model niet kent. Gecombineerd met AI-koopsignalen krijg je automatische suggesties voor doelgroepen.

S7 · Widgets & Journeys

Activeren zonder developer

Bouw widgets en journeys zelf, of laat de AI het doen

Een visuele element-picker voor wie liever klikt dan codeert, custom CSS/JS/HTML voor wie dat wel wil, en een AI-code-assistent die widgets bouwt of aanpast op verzoek, bijvoorbeeld "maak de knop blauw".

🧩

Widget builder

Klik een element aan op je eigen site en vervang, plaats voor, na of binnen. Formuliervelden worden automatisch herkend en gekoppeld (bijvoorbeeld een e-mailveld aan het interne klant-ID), met een preview voor je publiceert.

🔀

Journey builder

Stel triggers in op doelgroep- of event-niveau (zoals "add to cart" plus wachttijd), koppel een actie aan een integratie en volg de flow. Elke geactiveerde journey blijft onderdeel van dezelfde A/B-opzet.

S9 · Voor developers
API

Ook te bevragen door AI-agents

Naast een volledig gedocumenteerde, deterministische API (met instelbare rechten per key) is er een agentic API: agents zoals Claude Code kunnen conversationeel data opvragen in plaats van alle ruwe data zelf te verwerken. Aanzienlijk efficiënter in tokengebruik.

Beschikbaar

  • Standaard API, lezen én schrijven (bijvoorbeeld custom events pushen waar de pixel niet werkt)
  • Agentic API voor AI-agents
  • Kant-en-klare skill om direct in Claude Code te gebruiken

S11 · FAQ

Veelgestelde vragen over Sero CDP

Welke databronnen kan ik koppelen?

Nu: de Sero Pixel voor live gedragsdata en een directe koppeling met BigQuery voor historische order- en klantdata, via een wizard met automatische mapping. Directe koppelingen met Shopify, Magento en Shopware staan op de planning.

Moet ik elke personalisatie los laten testen?

Dat gebeurt automatisch. Elke widget of activatie draait standaard met een controlegroep, nooit als volledige takeover. Vooraf krijg je een inschatting van hoeveel bezoekers of dagen nodig zijn om een betrouwbaar resultaat te zien.

Kan ik zelf widgets bouwen zonder developer?

Ja. Met de visuele element-picker klik je een onderdeel van je site aan en pas je het aan, plaats je iets ervoor, erna of vervang je het. Wil je meer controle, dan kun je ook zelf custom CSS, JS of HTML gebruiken.

Welke tools kan ik koppelen voor activatie?

Standaard werkt Sero CDP samen met Klaviyo, Copernica en DeployTeq. Werk je met iets anders? Via een custom webhook met eigen payload is vrijwel elk systeem met webhook-ondersteuning te koppelen.

Is de CDP ook te gebruiken via een API?

Ja, er is een volledig gedocumenteerde API om te lezen én te schrijven, met instelbare rechten per key. Daarnaast is er een agentic API waarmee AI-agents zoals Claude Code conversationeel data kunnen opvragen.
